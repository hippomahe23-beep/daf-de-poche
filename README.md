# DAF de Poche · démo

Démo de l'application DAF de Poche : un projet d'étudiants en Master 1 Finance au Cnam Pays de la Loire. L'entreprise n'existe pas encore et les données sont fictives.

Site : https://hippomahe23-beep.github.io/daf-de-poche/

Tout tient dans `index.html`, construit depuis le prototype de l'application (`npm run build:html`). La démo tourne dans le navigateur : rien de ce qui est saisi n'est envoyé.
